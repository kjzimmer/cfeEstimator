# Vision

## The problem today
CFE employees currently use separate, disconnected AI chat sessions to work excavation jobs — estimating, planning, customer communication. There's no shared context between people working the same job, no consistent representation of company assets/rates/expertise, and no coordination. Every conversation starts from zero.

## What this product is
A single web app where CFE employees log in and collaboratively move a job from site visit and customer input through bid, project plan, and execution — centered on a conversational AI agent that:
- Has access to real company context (identity, products/services, assets, staffing, rates, past job data)
- Participates in a persistent, shared, multi-person conversation per project
- Builds up a structured project definition (SOW, location, materials, labor, billing, etc.) directly from that conversation and from uploaded site materials
- Gets better over time as more project outcomes accumulate

## What success looks like
- Short term: a working demo compelling enough that CFE wants to move from ad hoc AI usage to an actual subscription product built around their workflow
- Medium term: a tool CFE's estimators and PMs actually prefer over their current disconnected approach, because it's faster and more consistent
- Long term: a defensible, differentiated product — most estimating/construction software vendors haven't built anything like this yet

## What this is not (for now)
- Not a full project management replacement (billing, accounting, scheduling systems stay separate for now)
- Not aiming for enterprise-grade permissions, integrations, or scale on day one — this is deliberately staged, starting from a thin, real slice and adding functionality as the UX and requirements mature
